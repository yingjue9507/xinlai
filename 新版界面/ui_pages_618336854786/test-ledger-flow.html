礼薄列表 → 添加记录 流程测试

用户操作流程

第1步： 访问礼薄列表页面 打开礼薄列表
第2步： 点击某个礼薄进入详情页

在礼薄列表中点击任意一个礼薄项目

第3步： 在礼薄详情页点击右上角的"+"按钮

这会弹出添加记录的模态框

第4步： 在模态框中点击"手动录入"

这会跳转到添加记录页面，并带有正确的ledger_id参数

第5步： 验证添加记录页面的礼簿信息显示

应该显示当前礼簿的名称和类型，并自动选择对应的记录类型

预期验证点

  • ✅ 礼簿信息显示框应该显示正确的礼簿名称
  • ✅ 礼簿类型标识应该正确（我办事=绿色，参加别人的事=橙色）
  • ✅ 记录类型应该根据礼簿类型自动选择
  • ✅ 提示信息应该显示"正在使用指定的礼簿"
  • ✅ 保存记录时应该使用正确的礼簿ID
  • ✅ 不应该出现"未找到礼薄"的错误

调试检查点

打开浏览器开发者工具的控制台，检查以下信息：

  • URL参数解析是否正确
  • 礼簿详情API请求是否成功
  • 礼簿信息是否正确更新到界面
  • 记录类型自动选择是否执行
  • 保存记录时的礼簿ID是否正确

如果仍有问题

如果从礼薄列表进入仍然有问题，可能的原因：

  1. 礼簿ID传递过程中丢失或格式错误
  2. 礼簿详情API返回的数据结构不匹配
  3. 用户认证token过期或无效
  4. 礼簿不存在或用户无权限访问
  5. 前端JavaScript代码执行顺序问题

请检查控制台的具体错误信息，这将帮助定位问题。
